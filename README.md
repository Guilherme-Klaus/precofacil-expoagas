# 🏷️ PreçoFácil | EXPOAGAS 2026

> Experiência digital e interativa de precificação inteligente para o varejo, desenvolvida para a **EXPOAGAS 2026**.

---

## 🚀 Sobre o Projeto

O **PreçoFácil** é um microsite interativo projetado para transformar a complexidade de cálculos de preços (custos fixos, variáveis, impostos e margens) em uma experiência visual, rápida e fácil de demonstrar em feiras de negócios.

### ✨ Funcionalidades Principais
* **Simulador em Tempo Real:** Cálculo dinâmico de preço sugerido, lucro em reais, margem real e markup.
* **Estratégias Flexíveis:** Alterne facilmente entre o cálculo focado em **Margem de Lucro** ou **Markup**.
* **Copiloto de Precificação:** Insights automáticos baseados na saúde da margem do produto.
* **Ferramentas de Produtividade:** Opções para copiar o preço calculado, gerar link de compartilhamento, salvar cenários localmente (`localStorage`) e exportar/imprimir em PDF.
* **Contagem Regressiva:** Timer integrado para o evento EXPOAGAS 2026.
* **Design Responsivo:** Adaptado para navegação fluida em desktops, tablets e smartphones, contando também com uma folha de estilos otimizada para impressão.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias nativas focadas em performance e simplicidade (Zero dependências externas):
* **HTML5** (Semântico e estruturado)
* **CSS3** (Variáveis CSS, Flexbox, Grid Layout, Design System próprio com gradientes e tema escuro)
* **JavaScript Moderno (ES6+)** (Manipulação de DOM, APIs nativas como `Clipboard` e `LocalStorage`)
